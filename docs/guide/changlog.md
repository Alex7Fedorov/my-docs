# История изменений

## Версия 5.0.4 (2026)

### Новые возможности

- **Гибридная архитектура LMS/LXP** — объединение классического управления обучением с персонализированным опытом
- **Искусственный интеллект** — рекомендации контента на основе поведения и интересов пользователей
- **Адаптивные траектории обучения** — автоматическая подстройка программ под уровень знаний
- **Социальное обучение** — форумы, чаты, обмен опытом между сотрудниками
- **Микрообучение** — поддержка коротких образовательных модулей (3-7 минут)
- **Геймификация 2.0** — расширенная система достижений, лидерборды, виртуальная валюта

### Улучшения

- Полностью обновленный интерфейс с поддержкой темной темы
- Оптимизация производительности — загрузка страниц ускорена на 60%
- Мобильное приложение с офлайн-режимом
- Интеграция с популярными сервисами (Zoom, MS Teams, Google Workspace)
- Расширенная аналитика и отчетность для HR и L&D специалистов
- Поддержка SCORM 2004, xAPI (Tin Can), cmi5

### Технические изменения

- Миграция на микросервисную архитектуру
- Поддержка Kubernetes для масштабирования
- API v5 с улучшенной документацией
- Обновление системы безопасности (SSO, двухфакторная аутентификация)
