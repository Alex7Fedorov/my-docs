# Конфигурация системы eLearning Server 5G

Раздел **Конфигурация системы** — это центр управления платформой. Здесь задаются базовые параметры работы LMS/LXP, настраиваются интеграции с корпоративными системами, определяются правила безопасности и внешний вид портала. 

Правильная конфигурация — залог быстрого внедрения обучения, корректной работы сценариев адаптации и оценки, а также стабильной мотивации пользователей.

---

## 1. Основные параметры платформы
Базовые настройки, определяющие глобальное поведение системы.
- **Название организации:** Задает текст логотипа и заголовок вкладки браузера.
- **Часовой пояс:** Единый часовой пояс для расчета дедлайнов, расписания вебинаров и отчетности.
- **Язык по умолчанию:** Выбор языка интерфейса для новых пользователей.
- **Роль по умолчанию:** Какую роль (например, «Слушатель») автоматически получает пользователь при первой авторизации или синхронизации.
- **Формат дат и чисел:** Региональные стандарты отображения данных.

## 2. Интеграции и авторизация
Настройки подключения к корпоративным системам (HRIS, Active Directory и др.) для бесшовного входа и синхронизации оргструктуры.
- **SSO (Single Sign-On):** Настройка SAML 2.0 или OAuth 2.0 для входа без повторного ввода пароля.
- **LDAP / Active Directory:** Параметры подключения к корпоративному каталогу для импорта пользователей.
- **REST API:** Управление ключами доступа для двустороннего обмена данными с внешними сервисами (1С:ЗУП, SAP и т.д.).
- **Webhooks:** Настройка автоматических уведомлений внешним системам при наступлении событий (например, курс завершен).

## 3. Мотивация и геймификация
Включение и тонкая настройка механизмов вовлечения сотрудников в процесс обучения.
- **Система баллов и бейджей:** Задание стоимости прохождения элементов обучения и правил начисления наград.
- **Магазин вознаграждений (Loyalty Shop):** Настройка каталога товаров/привилегий, которые пользователи могут покупать за баллы.
- **Рейтинг и таблицы лидеров:** Настройка видимости рейтингов, периодов их обнуления и весовых коэффициентов.
- **Сертификация:** Глобальные правила автоматической генерации сертификатов по шаблонам при достижении результатов.

## 4. Оповещения и коммуникации
Управление каналами связи с пользователями для повышения вовлеченности и информирования о новых задачах.
- **Email-шлюзы:** Настройка SMTP-сервера для отправки системных писем (инвайты, напоминания, отчеты).
- **Push-уведомления:** Управление браузерными и мобильными пушами.
- **Интеграция с мессенджерами:** Подключение ботов в Telegram или Slack для пуш-уведомлений и микрообучения.
- **Шаблоны сообщений:** Редактирование текстов системных уведомлений с поддержкой подстановок (переменных).

## 5. Внешний вид и брендинг
Адаптация визуальной части платформы под корпоративный стиль (Brandbook) компании.
- **Логотип и Фавикон:** Загрузка изображений для шапки портала и иконки вкладки браузера.
- **Цветовая схема:** Настройка основных (Primary) и акцентных (Secondary) цветов интерфейса.
- **CSS-кастомизация:** Поле для ввода пользовательского CSS для нестандартного изменения дизайна.
- **Главная страница:** Выбор виджетов и компоновки лендинга для авторизованных пользователей.

## 6. Безопасность и аудит
Настройки, обеспечивающие защиту персональных данных и контроль действий администраторов.
- **Политика паролей:** Требования к сложности, сроку действия и запрету повторного использования паролей.
- **Сессии и IP-ограничения:** Настройка времени бездействия до авто-логаута и белых списков IP.
- **Журнал аудита:** Настройка глубины хранения логов действий администраторов и системных событий.
